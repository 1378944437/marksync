# MarkSync 主机权限候选包 · 2026-09-20

显示版本仍为 **1.6.2**；请用文件名中的 `host-permissions-20260920` 和 `SHA256SUMS.txt` 识别本批。包含空树同步、按主机授权与网页气泡移除；前批 `empty-sync` 包不包含权限修改。

## Chrome / Edge

1. 将 `marksync-chrome-v1.6.2-host-permissions-20260920.zip` 解压到固定目录，根目录应直接包含 `manifest.json`。
2. 打开 `chrome://extensions` 或 `edge://extensions`，开启“开发者模式”，点击“加载已解压的扩展程序”，选择该目录。
3. 更新已解压安装时，先保留原目录副本，再用本批文件替换原加载目录并点击“重新加载”。不要先卸载，卸载可能丢失扩展设置与本地快照。

## Firefox 临时测试

使用 Firefox 140 或更新版本（包内 manifest 的最低版本要求）。打开 `about:debugging#/runtime/this-firefox`，点击“临时载入附加组件”，选择 `marksync-firefox-v1.6.2-host-permissions-20260920-unsigned.xpi`；也可解压后选择根目录中的 `manifest.json`。

此包未签名，只用于临时加载，重启后临时安装失效；不是正式永久安装包。

## 权限验收

使用独立浏览器测试配置、专用 WebDAV 目录或测试 Gist。测试数据与原有同步设备隔离。以下为待执行步骤，不代表已经通过原生对话框验收。

| 场景 | 操作与预期 |
| --- | --- |
| 首次拒绝 | 填写 WebDAV 地址，点击保存或测试，在浏览器原生授权窗中拒绝。应显示具体错误、保留草稿，不提交新配置或访问该主机。 |
| 首次允许 | 再点击并允许。连接测试和同步正常，扩展管理页仅有目标主机的授权；网页不出现同步气泡，角标与面板日志仍可查看。 |
| 更换域名 | 改为另一测试主机，先拒绝再允许。拒绝时旧配置保留；允许后才能保存并访问新目标。历史授予的具体主机权限可能仍保留，可在管理页撤销。 |
| 导入配置 | 导入指向未授权主机的配置。拒绝授权时整个导入不保存；允许后才可导入。 |
| 撤权与恢复 | 在扩展管理页移除目标站点访问权限，再触发同步。应提示缺权，不把失败当成功或空云端；点击面板中的授权入口，允许后待上传任务恢复。 |
| Gist | 对 GitHub API 分别拒绝/允许，再测试连接、自动创建测试 Gist。需要独立 raw 下载主机时，面板应显示对应授权入口；允许后重试下载。创建结果未知时先核对已有 Gist，避免盲目重复创建。 |
| 升级 | 在单独测试配置中从旧包原路径重新加载本批。应清除旧全网授权、保留设置与本地状态，首次访问目标需要具体主机授权。若清除失败，应停止网络操作并提示管理页处理。 |

同时在工具栏 popup 与独立页面核对授权按钮；Firefox 重复上述适用场景。Gist 大文件 raw 路径需实际触发才算覆盖。空树行为可继续执行[两设备验收](../marksync-v1.6.2-empty-sync-20260920/INSTALL.md#两设备验收)，两端均安装本批构建。

记录浏览器版本、场景、通过/失败及脱敏现象；不要记录密码、Token 或真实服务地址。WebDAV/Gist 自动重定向现被拒绝，需要配置最终服务地址；主机授权不提供目录或端口隔离。凭证保存方式与加密格式未变。

## 校验与回退

运行 `Get-FileHash -Algorithm SHA256 <包路径>`，与同目录 `SHA256SUMS.txt` 比较。遇到问题先停止测试同步；可恢复原加载目录副本后重新加载。回退扩展文件不会撤销远端写入或书签变更，也可能重新引入旧版全网权限；测试数据恢复使用保留的快照。

本次核对 264 个输入、29 个构建文件摘要；Chrome 15 个、Firefox 14 个包内文件逐一匹配构建，manifest 引用均存在，两包均无必需主机权限或内容脚本。复用此前通过的 598 项单元测试、独立类型检查、双平台构建、11 项权限场景、1 项旧本地包重载升级及 7 项空树回归；此次打包没有重新运行这些测试。
