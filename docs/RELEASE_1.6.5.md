# MarkSync 1.6.5

## 修复

修复本地书签、云端备份、本地快照面板上下跳动。共用抽屉固定为可用视口高度的 90%，改为淡入，加载、空态及展开操作仅改变内部滚动内容；禁用列表自动滚动锚定。保留主动拖动关闭和横向宽度稳定性。

## 验证和限制

版本更新后重新执行 56 个测试文件、611 项用例及双端构建（含类型检查），全部通过。两份 manifest 均为 1.6.5，既有包体积和 Browserslist 数据过期警告保留。

UI 源码已通过 18 个逐帧位置场景（横纵位移均为 0px）、2 个控制台滚动条场景、48 个桌面/手机/平板模拟交互场景，包含展开和恢复确认取消后的高度/位置断言。记录见[抽屉位置验收](validation/2026-09-20-panel-position/README.md)。这些检查运行于补丁版本号更新前，版本号不改变 UI 实现。

手机为隔离 Edge 触屏、UA 和视口模拟，不代表所有实际手机浏览器均通过；实体手机、原生 Firefox UI 仍待实际使用核对。旋转或键盘导致真实视口变化时，面板仍按视口调整。空列表保留相同高度以避免后续加载跳变。

## 发布

用户授权“提交发布”。仅修改根版本号，双端 manifest 自动引用。提交前执行单元测试、双端构建与类型检查；远端 Test CI 通过后创建 GitHub Release，由现有工作流生成 Chrome ZIP 和签名 Firefox XPI。失败时保留源提交与旧发行，不改写历史。

状态以 [v1.6.5 Release](https://github.com/1378944437/marksync/releases/tag/v1.6.5) 和 Actions 实际结果为准，不预先宣称签名上传成功。
