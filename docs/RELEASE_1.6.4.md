# MarkSync 1.6.4

## 界面与交互

- 修复本地书签、云端备份、本地快照面板打开及列表变长时的宽度波动。
- 大屏抽屉居中限宽，手机适配横竖屏、底部安全区和至少 44px 的列表操作热区。
- 修复控制台同步区域底栏越界；统计卡片直接说明入口用途。
- 备份和快照卡片支持键盘展开，优化长名称与按钮层级，保留恢复/删除确认。
- 图标导航保留无障碍名称，中英文说明同步更新。

## 验证与边界

版本更新为 1.6.4 后，重新执行 56 个测试文件、611 项用例及 Chrome/Firefox 构建（含类型检查），全部通过。两份生成 manifest 均引用根版本 1.6.4。既有 Browserslist 数据过期及包体积警告保留。

发布前 UI 源码已通过 48 个桌面/手机/平板模拟交互场景、18 个宽度回归场景、2 个控制台滚动条检查。原生 popup 连续打开三次均为 360×560，手机同步/设置页 10 个尺寸检查通过。详见[多端验收记录](validation/2026-09-20-responsive-panels/README.md)。这些测试发生于版本号更新前，版本号更新不改变 UI 实现。

实体手机、原生 Firefox UI、系统文字缩放及刘海/手势区仍待实际使用核对；不将模拟结果等同于全机型通过。本轮不更改同步协议、凭证存储或加密格式。

## 发布流程

用户明确授权“提交发布”。根版本号更新为 1.6.4；提交前执行单元测试与双端构建，推送后确认 Test CI，再创建 GitHub Release，由原有工作流打包 Chrome ZIP 并签名 Firefox XPI。失败时保留提交及 v1.6.3 发行，不覆盖旧发行或改写历史。

公开发行和安装包状态以 [v1.6.4 Release](https://github.com/1378944437/marksync/releases/tag/v1.6.4) 与 Actions 实际结果为准；本文件不预先宣称远端签名上传成功。
