# 空树同步交付记录

状态：已保存的候选构建；真实环境待验证。授权为“发送端显式确认、接收设备首次再确认、保留恢复依据”，不包含提交、推送、版本升级或发布。

## 结果

- 删除最后一条范围内书签后，自动同步会停在确认处；面板显示目标、实际清空范围及数量。用户明确发布后才生成空备份。普通防误删开关不能绕过此确认。
- 每台设备首次接收清空版本需要确认；自动拉取及自动合并都会停止。提示明确说明未上传修改也会被删除，用户仍可选择手动上传保留本地内容。
- 确认有效期 15 分钟，绑定操作方向、目标、范围、目录及书签内容、云端版本。状态变化需要重新确认；相同清空版本已接收且本地未变时跳过重复操作。
- 发布前保存完整本地快照，本次不删除任何云端历史，包含时间窗口内的前一版本。收到未知写入结果后先读取云端；读到同内容空版本会转为接收确认，不重复发布。
- 接收前保存完整本地快照。删除失败保留恢复记录并阻断后续同步；可恢复操作前内容。只处理本机范围与清空载荷中系统文件夹的交集，Firefox 专有菜单不进入空载荷。
- 中英文 README 与确认卡片同步更新。协议与约束的权威正文见 [架构补充](../REFACTORING.md)，其余产品事项仍见 [后续方案](FOLLOW_UP_PLAN_2026-09-19.md)。

## 限制与切换安排

- 真实 WebDAV/Gist 服务、Firefox 实际交互、手机和原生 popup 生命周期未执行。本机浏览器验收不代替这些证据。
- 空备份采用新正文格式，旧数组读取器会停止。本轮根版本仍为 1.6.2，不能仅凭显示版本号判断是否支持；实际使用前让所有设备安装包含此改动的构建。更早历史版本的错误处理未全面验证，不支持混用。
- 后续非空上传仍遵循原保留数量和时间策略；清空前云端版本与成功操作的本地快照不是永久归档。需要长期回滚依据时另行导出保留。
- 当前 WebDAV/Gist 没有跨设备 CAS；上传前再次核对与上传后读回不能消除最后一个网络窗口内的竞争。本轮没有改变该存储契约。
- sender 在用户自行删空之后只能保存当时的完整本地树；已删除内容依靠先前云端版本或既有快照恢复。尚无历史备份时无法补造删除前内容。
- E2E 外层及 KDF、凭证持久保存和主机权限均保持原策略。没有初始化仓库、暂存、提交、推送、签名、发布或变更版本号。

下一步为使用包含本批改动的构建进行真实设备验收；发布、提交与推送需另行明确授权。
