# MarkSync 1.6.3

## 变化

- 新增空树同步：发送端确认发布清空，接收端确认后保存完整快照再应用；保留清空时的云端历史，保护范围外书签。
- 主机权限改为按需申请；拒绝或撤销权限时暂停相关网络操作，保留待上传及恢复状态。取消网页同步气泡，保留角标与面板日志。
- Gist 测试和创建移到后台，页面重开可找回最近成功创建的 ID；加密迁移支持安全取消和中断后继续。
- 修复不可恢复的安全快照和不可读取备份仍被发布的问题；修复已确认清空后的新增书签智能上传，以及空树确认与加密迁移互相阻塞的问题。
- 加固恢复、快照保留、WebDAV 文件名编码、Gist raw 下载校验、备份清理错误反馈和后台调度。

## 升级说明

- 使用清空同步前，请让同一目标上的全部设备升级；旧版本会拒绝新的清空格式。普通备份与 E2E 密文格式不变，历史密文仍需原密码。
- 升级会清理旧的全网站授权，请在面板重新授权实际存储主机；Gist 大文件可能需要额外授权可信 raw 主机。
- URL 白名单为 `http:`、`https:`、`ftp:`、`ftps:`。上传、快照及恢复均整树校验，遇到 bookmarklet、`file:`、`mailto:` 等会停止，不静默丢弃。完整安全快照也包含同步范围外书签。
- 本地范围为空、加密迁移提示先确认同步时，请完成清空发布或接收，再重新设置加密；预检失败不再留下阻断确认的迁移记录。
- WebDAV 和 Gist 网络请求拒绝自动重定向，需配置最终服务地址。凭证存储方式与 KDF 参数未改。

## 验证

- 56 个测试文件、611 项用例通过，含本轮新增 13 项针对发布前四项发现的回归。
- 独立 app strict 类型检查、Chrome/Firefox 全量构建通过；两份 manifest 版本均为 1.6.3。
- 新构建通过隔离 Edge 的 11 项权限场景、1 项旧包重载升级、7 项空树场景，包含真实一分钟闹钟和部分恢复中断。
- 输入、构建摘要及检查记录见 [1.6.3 证据](validation/2026-09-20-release-1.6.3/evidence.json)。既有 1.6.2 候选包与审查复现记录为历史证据。

原生授权对话框 Accept/Cancel、真实 WebDAV/Gist、原生 popup 生命周期、Firefox 实际交互和商店升级尚未验证；不将模拟授权或临时扩展重载等同于这些场景通过。已知主包体积与 Browserslist 提示保留。按既有决定，真实环境验收延后到实际使用。

## 发布与修复依据

用户授权：“修复后再提交发布”。本轮根版本由 1.6.2 更新为 1.6.3，两壳自动引用；不修改签名凭据和发布工作流。先提交并确认远端 Test 工作流，再发布 GitHub Release，由现有工作流生成 Chrome ZIP 和签名 Firefox XPI。失败时停止后续发布步骤，保留源提交与旧产物；未知外部结果先查状态。

公开状态与安装包以 [v1.6.3 Release](https://github.com/1378944437/marksync/releases/tag/v1.6.3) 和 [Actions](https://github.com/1378944437/marksync/actions) 的实际结果为准。此记录描述源提交中的实现与本地证据，不预先宣称远端签名或上传成功。

四项原始发现见[发布前审查](PRE_RELEASE_REVIEW_2026-09-20.md)。修复位置：`SnapshotManager.createSnapshot` 和 `BookmarkRepository.createCloudBackup` 在共享入口校验；`requireEmptyReceive` 仅为智能方向判断允许已确认版本后的本地编辑，显式覆盖仍确认；加密迁移仅在 `onPrepared`、外部写入前记录候选状态，兼容清理旧版无路径记录。
