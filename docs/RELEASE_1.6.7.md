# MarkSync 1.6.7

## 修复与优化

- 隐藏滚动条并移除预留槽位，修复设置页面左右留白不对称，保留滚轮、触摸及键盘滚动。
- 修复 Edge 原生弹窗绘制时的 resize 事件立即关闭问号提示；支持点击、悬停和键盘聚焦，补齐云端保留份数说明。
- 保留份数输入仅显示一组加减按钮，仍可直接输入；备份文件间隔保留下拉选择。
- 简化名称为「本地保留份数」「云端保留份数」「备份文件间隔」，同步英文名称。
