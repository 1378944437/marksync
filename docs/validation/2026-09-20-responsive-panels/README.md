# 多端界面与交互验收（2026-09-20）

## 本轮范围

在上一批宽度稳定性修复之上优化共用抽屉、统计入口、备份/快照卡片与控制台布局。已保存，未提交、推送、签名或发布，根版本号保持 1.6.3；本目录不代表已发布安装包。

- 大屏抽屉居中限宽 42rem，手机窄屏贴合视口；标题/关闭区固定，列表独立滚动并保留底部安全区。
- 手机抽屉按钮至少高 44px，关闭按钮至少 44×44px；同时使用应用手机识别和 coarse pointer，覆盖扩展宿主误报鼠标设备的情况。
- 控制台同步区使用 flex 分配剩余高度，快照底栏保持在面板内部。
- 统计卡片直接显示入口说明；隐藏文字后的图标导航仍有名称。
- 备份/快照主行使用原生 button，支持 Enter/Space 展开；恢复/删除是独立操作，保留确认。长标题限制行数，设备名称与图标对齐。
- 中英文 README 同步说明。

## 限制与下一步
