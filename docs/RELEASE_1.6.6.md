# MarkSync 1.6.6

## 修复

- 新设备本地没有书签时，可用原密码启用 E2E 并拉取已有加密备份；验证成功仅保存本机设置，不上传、不删除、不修改同步基线，也不要求先发布清空。
- 错误密码、损坏备份或验证期间云端版本变化时保留原设置；已启用后的改密与候选迁移仍执行原迁移流程。
- 取消主弹窗首次横移、卡片上移，固定计数加载行高度，并稳定主滚动区的滚动条占位。

## 验证及限制

版本更新为 1.6.6 后，56 个测试文件、616 项用例及 Chrome/Firefox 构建（含类型检查）全部通过。两份 manifest 均为 1.6.6，既有包体积与 Browserslist 过期提示保留。

加密修复说明与用例见 [空设备加入加密库](E2E_JOIN_FIX_2026-09-20.md)。首页修复的八次首次渲染检查、原生 popup 三次尺寸检查与手机同步/设置页十次检查见 [主弹窗记录](validation/2026-09-20-popup-startup/README.md)及其 viewport/results.json。UI 证据复用于相同 UI 实现，版本号和后续加密业务修改不改变其覆盖的未配置首页布局。

手机为 Edge 视口/UA 模拟，实体手机、原生 Firefox UI 和真实云端服务未验收。首页测试不代表所有异步权限、错误提示、语言切换均无布局变化。现有凭证保存方式和密文格式未改变。

## 发布流程

用户明确授权提交发布。更新根版本为 1.6.6，执行测试与双端构建后提交推送；Test CI 通过后创建 Release，复用现有工作流生成 Chrome ZIP 和签名 Firefox XPI，再校验实际附件。失败时保留旧发行和源提交，不重写历史。

公开状态以 [v1.6.6 Release](https://github.com/1378944437/marksync/releases/tag/v1.6.6) 和 Actions 为准，不预先宣称签名上传成功。
