## 2. 修复行为

| 项目 | 最终行为 |
| --- | --- |
| Gist 创建 | 后台收到创建成功结果后，独立保存最近创建的 ID/端点；重开设置页可填入草稿，核对 Token 后仍须显式保存。原连接不会被创建操作替换；后台拒绝同时创建。保存失败提示已创建的 ID，不自动重发 |
| 加密迁移提交边界 | 设置、基线及 committed 标记同次保存；收尾失败后继续/取消只清理记录，保留生效备份。旧记录通过已保存的目标、基线路径和加密设置识别已提交状态 |
| 未提交迁移取消 | 校验候选内容及目标，确认文件已删除才解除迁移阻塞；删除失败、内容变化或删除未生效时保留记录。文件已删但清理记录失败可重试 |
| Gist 迁移取消 | 记录迁移前当前版本；专用回滚一次 PATCH 更新索引与删除候选，并读回。保留更晚的当前版本；普通 deleteFile 仍禁止删除当前版本。旧记录缺少上一版本信息时停止取消，提示继续迁移 |
| 快照保护 | 回归测试锁定恢复快照不被保留数量清理、单删或全删；记录解除后可以删除。清理失败不把已落库快照误报为创建失败 |
| 拉取快照时机 | 云端下载、校验及数量安全检查通过后创建快照；同一份当前本地树用于安全检查与快照。快照成功、恢复记录保存后才写书签 |
| 恢复出厂 | 先检查未完成恢复/迁移，关闭自动和定时同步；移除配置/缓存时保留当前操作锁和恢复标志；最后删除快照。前面失败不删除快照，删除失败可重试 |
| 云端清理 | 等待列表缓存失效。备份列表读取/删除失败抛错，不再返回“无需清理”；上传已验证并提交基线后，清理失败以“上传成功，但清理失败”显示 |
| WebDAV 空地址 | 测试连接前拦截空白 URL，使用现有 URL 提示，不发出后台测试请求 |
| 类型与调度 | core barrel 显式导出同步策略 smartSync，消除 TS2308；删除未实现的 github 驱动类型并在运行时拒绝未知类型。scheduler 注释及测试明确配置由后台对账 |

## 4. 决策、限制与剩余工作

- 用户确认保留现有 URL 白名单，README 中英文已同步说明特殊协议整树拒绝及同步影响。
- 用户确认凭证存储保持现状；空树同步、权限收敛独立下一批；KDF 不切换格式，本轮交付 [后续方案](FOLLOW_UP_PLAN_2026-09-19.md)。
- Gist 创建无法保证网络结果未知或本地持久化失败时自动找回 ID；不要重复创建来猜测结果。最近成功结果只保留一条，不能代替服务端历史列表。
- Gist 回滚沿用现有读回协议，没有分布式 CAS；WebDAV 在内容校验与 DELETE 之间也没有新增 ETag 前置条件。真实并发服务语义不在本次证明范围。
- 浏览器验收使用扩展大屏页面，不能等同于工具栏 popup 关闭或后台自然休眠验收；浏览器连接了自动化工具。Gist 取消的索引语义由单元测试覆盖，浏览器取消测试使用本机 WebDAV。
- 浏览器中仍需核对：原生 popup 关闭与后台生命周期、真实服务权限/限流/并发、Firefox 实际交互。缺少这些证据时，面向真实环境的交付仍是待验证候选。
- 本次构建仍提示 Browserslist 数据过期及主包大于 500 kB；没有通过改阈值隐藏提示。原有超过 300 行的 webdav-client.test.ts 在本轮接手修复中未继续修改；其余本轮直接编辑的源文件/测试/脚本未超过 300 行。
